# Linear Control Systems

This repository contains my **homeworks, projects, and research-related work** in **Linear Control Systems**, developed during my academic studies under the supervision of **Prof. Taghirad**.

The purpose of this repository is to document my learning process in control theory and to provide clear, reproducible implementations of theoretical concepts applied to engineering systems.

---

## Contents

### Homework Assignments
Solutions and simulations covering fundamental topics in linear control systems, including:
- State-space modeling
- Stability analysis and Lyapunov methods
- Controllability and observability
- State feedback and pole placement
- Linear Quadratic Regulator (LQR)
- Observer design

Each homework folder may include problem statements, analytical derivations, code implementations, and simulation results.

---

### Projects
Course and independent projects focused on practical control system analysis and design, such as:
- Dynamic system modeling
- Controller design and performance evaluation
- Robustness and sensitivity analysis
- Simulation and validation

Projects aim to bridge theoretical concepts with practical implementation.

---

### Research & Explorations
Notes, experiments, and preliminary research related to linear control systems, which may include:
- Advanced state-space techniques
- Optimal and robust control methods
- Connections between classical and modern control theory

This section reflects ongoing study and exploration.
